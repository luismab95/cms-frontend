1. Sincronización del esquema

Obligatorio

Habilita la sincronización de la estructura de la base de datos mediante la configuración del proyecto.

Configuración requerida .env 
DB_SYNCHRONIZE=true

Activa esta variable en el archivo de entorno que utiliza el servicio.

Comando de ejecución

cd cms-lib-database && pnpm start:dev

Precaución: habilitar la sincronización puede modificar el esquema existente. En producción, utiliza migraciones controladas y una copia de seguridad.

Proyecto: cms-lib-database

2. Carga de datos iniciales

Recomendado

Ejecuta los seeders para inicializar los catálogos, las plantillas, la internacionalización y los roles del sistema.

Configuración requerida .env 
DB_SEEDER=true

Activa la variable para habilitar la carga de datos iniciales.

Comando de ejecución

cd cms-lib-database && pnpm start:dev

Importante: verifica si los seeders admiten ejecuciones repetidas sin duplicar registros. Desactiva la variable después de completar la carga si así lo requiere la implementación.

Proyecto: cms-lib-database
